# Личные финансы

Консольное приложение для ведения личного бюджета. Пользователи управляют категориями, доходами, расходами и лимитами; приложение строит сводку, предупреждает о приближении к лимиту и сохраняет кошельки в JSON.

## Запуск

Нужен Python 3.11 или новее. Внешние библиотеки не требуются.

```bash
python -m finance_app
```

Можно задать другой каталог для файлов данных: `python -m finance_app --data-dir ./my-data`.

Создайте учётную запись командой `register alice pass1234`. Пароли хранятся в виде PBKDF2-хешей. Файлы кошельков и пользователей находятся в каталоге данных; кошелёк сохраняется после изменений и при выходе.

## Команды

Сначала выполните `help` для полного списка. Пример с пробелами в названиях:

```text
register alice pass1234
category expense "Коммунальные услуги"
category expense Еда
category income Зарплата
expense Еда 300
income Зарплата 20000 2025-01-15 Аванс
budget Еда 4000
rename-category Еда "Продукты"
total expense "Продукты,Коммунальные услуги"
report
export report.json json
export report.csv csv
import report.csv
exit
```

Поддерживаются команды `register`, `login`, `logout`, `category`, `rename-category`, `income`, `expense`, `budget`, `report`, `total`, `transfer`, `export`, `import`, `help`, `exit`. `total` принимает список категорий через запятую и границы периода ISO (`с YYYY-MM-DD по YYYY-MM-DD`). Для импорта укажите файл `.json` или `.csv`; CSV содержит операции, а JSON — полный снимок кошелька. Перевод выполняется по логину зарегистрированного получателя, даже если тот ещё не входил в приложение в текущем запуске.

## Архитектура

- `models.py` — кошелёк, операции, проверка денежных сумм.
- `storage.py` — интерфейс хранилища и файловое JSON-хранилище.
- `service.py` — авторизация, категории, бюджеты, сводки, переводы и обмен данными.
- `cli.py` — интерактивный командный цикл и форматирование отчёта.
- `__main__.py` — точка входа.

Операции и кошельки загружаются в память приложения при входе. JSON-файлы используются для сохранения кошельков между запусками; пароли хранятся отдельно в виде PBKDF2-хешей. Состояние записывается при изменениях и при выходе.

## Проверка

Запустить unit- и интеграционные тесты:

```bash
python -m unittest discover -s tests -v
```

Тесты используют временные каталоги и не меняют пользовательские данные.
